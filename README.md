RandomnessBeacon – On-Chain Randomness Source
RandomnessBeacon provides verifiable randomness for use in raffles, gaming, lotteries, and unpredictable allocation decisions directly on-chain.

Core Capabilities
- Commit–reveal randomness generation workflow
- Fair, bias-resistant result computation
- Fully transparent randomness auditability
- Designed as a shared randomness module for other contracts

Key Functions
commit-random, reveal-random, get-latest-random, is-commit-open
